## 🚀 功能特点

### 1️⃣ Coze AI 智能回复（新）
- 调用您在 Coze 平台搭建的 AI Agent
- 自动保持对话上下文，支持连续对话
- 识别商品信息，提供针对性回复
- 显示"正在输入..."动画，提升体验
- 当 AI 不可用时，自动使用兜底回复

### 2️⃣ 图片上传
- 支持相册选择和拍照
- 自动上传到云存储
- 显示上传进度

### 3️⃣ 商品卡片
- 默认显示当前商品
- 可选择其他商品
- 点击卡片跳转详情

### 4️⃣ 消息展示
- 左侧：客服消息（白色气泡）
- 右侧：用户消息（蓝色气泡）
- 自动滚动到最新消息

## ⚙️ 配置选项

### 修改客服自动回复
在 `index.js` 的 `autoReply()` 方法中修改回复逻辑。

### 修改商品加载数量
在 `loadProductList()` 方法中修改 `.limit(20)` 的数值。

### 启用真实客服
替换 `autoReply()` 方法为调用实际客服接口。

## 🤖 Coze AI 配置

> ⚠️ **重要**：使用前请先完成 Coze AI 配置

### 快速配置

1. **获取 Coze 凭证**：
   - 在 [Coze 平台](https://www.coze.cn/) 创建 Bot
   - 获取 API Key 和 Bot ID

2. **配置云函数**：
   - 打开 `cloudfunctions/callCozeAgent/index.js`
   - 替换 `YOUR_COZE_API_KEY` 和 `YOUR_BOT_ID`

3. **部署云函数**：
   - 右键点击 `callCozeAgent` 文件夹
   - 选择「上传并部署：云端安装依赖」

4. **测试验证**：
   - 在小程序中发送消息
   - 观察 AI 回复效果

### 详细文档

完整的配置步骤请参考：[Coze AI 客服集成指南](../../../Coze-AI客服集成指南.md)
