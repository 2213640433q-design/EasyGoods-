## 📋 部署步骤

### **第1步：创建 user_coupons 集合** 📊

1. 打开微信开发者工具
2. 点击 "云开发" 按钮
3. 选择 "数据库" 标签
4. 点击 "+" 创建集合
5. 输入集合名称：`user_coupons`
6. 点击 "确定"

#### **配置权限：**

1. 点击 `user_coupons` 集合
2. 点击 "权限设置"
3. 选择 "自定义安全规则"
4. 输入以下规则：

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

5. 点击 "保存"

✅ 完成后，用户只能查看和使用自己的优惠券。

## ⚠️ 常见问题

### **问题1：没有可领取的优惠券**

**原因：** `coupons` 集合中没有有效的优惠券模板

**解决方案：**
```
需要先在云开发控制台的 coupons 集合中添加优惠券模板数据。

可以使用之前创建的 coupons_demo.csv 文件导入测试数据。
```

### **问题2：领取优惠券失败**

**错误：** "您已领取过该优惠券"

**原因：** 每个用户只能领取一次同一张优惠券

**解决方案：**
```
1. 检查 user_coupons 集合
2. 删除已领取的记录（测试时）
3. 或者创建新的优惠券模板
```

### **问题3：订单中没有可用优惠券**

**原因：** 订单金额不满足优惠券的最低消费要求

**解决方案：**
```
1. 检查优惠券的 minAmount 字段
2. 确保订单金额（不含押金）>= minAmount
3. 或者调整优惠券的最低消费金额
```

### **问题4：优惠券未标记为已使用**

**原因：** 订单支付时优惠券状态更新失败

**解决方案：**
```
1. 检查 updateOrderStatus 云函数日志
2. 查看是否有错误信息
3. 确认 user_coupons 集合权限配置正确
```

## 🎯 优惠券类型说明

### **类型1：满减券（reduce）**

```javascript
{
  type: 'reduce',
  discountValue: 10,  // 减10英镑
  minAmount: 50       // 满50可用
}
```

**计算规则：**
- 订单金额 >= 50 → 直接减10英镑
- 订单金额 < 50 → 不可使用

**示例：**
- 订单金额：60英镑 → 优惠后：50英镑
- 订单金额：40英镑 → 不可用

---

### **类型2：折扣券（discount）**

```javascript
{
  type: 'discount',
  discountValue: 10,   // 9折（100-10=90%）
  minAmount: 100,      // 满100可用
  maxDiscount: 20      // 最高优惠20英镑
}
```

**计算规则：**
- 订单金额 >= 100 → 打9折
- 优惠金额 = 订单金额 × 10%
- 如果优惠金额 > maxDiscount，则优惠金额 = maxDiscount

**示例：**
- 订单金额：150英镑 → 优惠15英镑 → 支付135英镑
- 订单金额：300英镑 → 优惠30英镑，但最高20英镑 → 支付280英镑
- 订单金额：80英镑 → 不可用
