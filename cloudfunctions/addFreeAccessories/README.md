# 附赠配件批量更新云函数

## 📦 功能说明

为所有商品自动添加"附赠配件"字段，根据商品类别和名称智能分配配件。

## 🎯 附赠配件规则

### 按类别分配：
- **相机**：相机包×1、镜头盖×1、相机带×1、清洁布×1
- **镜头**：镜头盖×2、镜头袋×1、清洁布×1
- **灯光**：灯罩×1、反光板×1、电源线×1
- **稳定器**：快装板×1、平衡块×2、收纳袋×1、充电线×1
- **音频**：防风罩×1、转接线×1、收纳袋×1
- **存储**：读卡器×1、保护盒×1
- **其他**：说明书×1、保修卡×1

### 特殊商品：
- **Sony 系列**：相机包×1、备用电池×1、充电器×1、镜头盖×1、相机带×1、清洁套装×1
- **Canon 系列**：相机包×1、镜头盖×1、相机带×1、USB线×1、清洁布×1
- **DJI 系列**：快装板×2、平衡块×3、收纳袋×1、充电线×1、三脚架底座×1
- **Rode 系列**：防风罩×2、转接线×1、收纳袋×1、电池×2

## 🚀 使用方法

### 1. 部署云函数
在微信开发者工具中：
1. 右键点击 `cloudfunctions/addFreeAccessories` 文件夹
2. 选择"上传并部署：云端安装依赖"

### 2. 调用云函数
在小程序中调用（仅管理员使用）：

```javascript
wx.cloud.callFunction({
  name: 'addFreeAccessories',
  success: res => {
    console.log('✅ 批量更新成功:', res.result)
    wx.showToast({
      title: `成功更新 ${res.result.data.successCount} 个商品`,
      icon: 'success'
    })
  },
  fail: err => {
    console.error('❌ 批量更新失败:', err)
  }
})
```

### 3. 在控制台直接测试
1. 打开云开发控制台
2. 进入"云函数"
3. 找到 `addFreeAccessories`
4. 点击"测试"按钮
5. 直接运行（不需要参数）

## 📝 返回格式

```json
{
  "success": true,
  "message": "批量更新完成",
  "data": {
    "total": 50,
    "successCount": 50,
    "errorCount": 0
  }
}
```

## ⚠️ 注意事项

1. 这个云函数会**覆盖**现有的 `freeAccessories` 字段
2. 建议在测试环境先运行一次
3. 运行前建议备份数据库
4. 仅管理员可调用

## 🔄 重新运行

如果需要修改附赠配件规则：
1. 修改 `index.js` 中的 `freeAccessoriesMap`
2. 重新上传部署云函数
3. 再次调用云函数更新数据
