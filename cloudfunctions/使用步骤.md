### 第五步：在小程序中测试云函数（5分钟）

#### 1. 测试 testCloud（验证环境）

**在任意页面的 .js 文件中添加：**

```javascript
// 测试云开发环境
async testCloudFunction() {
  wx.showLoading({ title: '测试中...' })
  
  try {
    const res = await wx.cloud.callFunction({
      name: 'testCloud',
      data: {
        message: '来自小程序的测试消息'
      }
    })
    
    console.log('云函数返回:', res)
    
    if (res.result.success) {
      wx.showModal({
        title: '🎉 测试成功！',
        content: res.result.message + '\n\nOpenID: ' + res.result.data.openid,
        showCancel: false
      })
    }
  } catch (err) {
    console.error('云函数调用失败:', err)
    wx.showModal({
      title: '❌ 测试失败',
      content: '错误：' + err.errMsg,
      showCancel: false
    })
  } finally {
    wx.hideLoading()
  }
}
```

**调用方式：**
```javascript
// 在页面的某个按钮点击事件中
onTestTap() {
  this.testCloudFunction()
}
```

#### 2. 测试 getProducts（获取商品）

**在 pages/index/index.js 中添加：**

```javascript
// 从云数据库获取商品列表
async loadProductsFromCloud() {
  wx.showLoading({ title: '加载中...' })
  
  try {
    const res = await wx.cloud.callFunction({
      name: 'getProducts',
      data: {
        mainCategory: this.data.currentMainCategory || '',
        subCategory: this.data.currentSubCategory || '',
        page: 1,
        pageSize: 20
      }
    })
    
    console.log('商品列表:', res)
    
    if (res.result.success) {
      this.setData({
        productList: res.result.data
      })
      
      wx.showToast({
        title: `加载成功，共${res.result.pagination.total}件商品`,
        icon: 'success'
      })
    } else {
      throw new Error(res.result.message)
    }
  } catch (err) {
    console.error('获取商品失败:', err)
    wx.showToast({
      title: '加载失败',
      icon: 'none'
    })
  } finally {
    wx.hideLoading()
  }
}
```

**替换现有的加载方法：**
```javascript
onLoad() {
  // ... 其他代码 ...
  
  // 🔥 注释掉原来的静态数据加载
  // this.filterProducts()
  
  // ✅ 使用云数据库加载
  this.loadProductsFromCloud()
}
```

## 🐛 常见问题排查

### 问题1：云函数上传失败

**错误提示：**
```
上传失败：network error
```

**解决方法：**
1. 检查网络连接
2. 关闭 VPN 或代理
3. 重启微信开发者工具
4. 重新上传

---

### 问题2：调用云函数返回 -1

**错误提示：**
```
errCode: -1
errMsg: "cloud.callFunction:fail"
```

**解决方法：**
1. 确认云函数已上传成功
2. 检查 app.js 中的环境ID是否正确
3. 在控制台查看云函数日志
4. 重新编译小程序

---

### 问题3：数据库查询返回空数组

**可能原因：**
- 数据库集合为空
- 权限设置错误
- 查询条件不匹配

**解决方法：**
1. 在控制台检查数据库是否有数据
2. 确认权限设置为"所有用户可读"
3. 简化查询条件测试
4. 查看云函数日志

---

### 问题4：无法获取 openid

**错误提示：**
```
openid: undefined
```

**解决方法：**
1. 确认已在 app.js 中初始化云开发
2. 检查是否在真机或模拟器上测试（开发者工具可能无法获取）
3. 等待云环境初始化完成
4. 重新编译小程序

## 📊 性能优化建议

### 1. 数据缓存
```javascript
// 缓存商品列表，避免频繁请求
const CACHE_KEY = 'products_cache'
const CACHE_TIME = 5 * 60 * 1000  // 5分钟

async loadProductsWithCache() {
  const cache = wx.getStorageSync(CACHE_KEY)
  const now = Date.now()
  
  // 如果缓存有效，直接使用
  if (cache && cache.timestamp && now - cache.timestamp < CACHE_TIME) {
    this.setData({ productList: cache.data })
    return
  }
  
  // 否则从云端获取
  const products = await this.loadProductsFromCloud()
  
  // 保存到缓存
  wx.setStorageSync(CACHE_KEY, {
    data: products,
    timestamp: now
  })
}
```

### 2. 分页加载
```javascript
// 使用分页，提高加载速度
data: {
  page: 1,
  pageSize: 10,
  hasMore: true
}

// 上拉加载更多
onReachBottom() {
  if (!this.data.hasMore) return
  
  this.setData({
    page: this.data.page + 1
  })
  
  this.loadMoreProducts()
}
```

### 3. 请求去抖
```javascript
// 避免频繁请求
let searchTimer = null

onSearchInput(e) {
  const keyword = e.detail.value
  
  clearTimeout(searchTimer)
  searchTimer = setTimeout(() => {
    this.searchProducts(keyword)
  }, 500)  // 500ms 后才执行搜索
}
```
