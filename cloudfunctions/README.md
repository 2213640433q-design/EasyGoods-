## 🚀 使用说明

### **部署云函数：**
```
右键云函数文件夹 → "上传并部署：云端安装依赖"
```

### **测试云函数：**
```javascript
wx.cloud.callFunction({
  name: '云函数名称',
  data: { 参数 }
})
```

### **查询数据库：**
```javascript
const db = wx.cloud.database()
db.collection('集合名称').get()
```
