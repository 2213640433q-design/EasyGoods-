# 城市信息双向同步说明

## 🎯 功能概述

实现了首页的城市选择与用户个人资料中的城市信息的双向同步，确保用户在任何地方修改城市后，都能在其他地方看到更新。

## 🔄 同步逻辑

### 1. **首页选择城市 → 用户信息**

当用户在首页左上角选择城市时：
1. 更新首页显示的城市（`cityName`）
2. 保存到本地存储 `CITY_NAME`
3. 同步到用户信息本地存储 `userInfo.city`
4. 同步到云端数据库 `users` 集合

```javascript
// pages/index/index.js
async onCitySelect(e) {
  const name = e.currentTarget.dataset.name
  
  // 1. 更新首页显示
  this.setData({ cityName: name })
  
  // 2. 保存到 CITY_NAME
  wx.setStorageSync('CITY_NAME', name)
  
  // 3. 同步到用户信息
  const userInfo = wx.getStorageSync('userInfo') || {}
  userInfo.city = name
  wx.setStorageSync('userInfo', userInfo)
  
  // 4. 同步到云端
  await wx.cloud.callFunction({
    name: 'updateUserInfo',
    data: { city: name }
  })
}
```

---

### 2. **用户信息修改城市 → 首页**

当用户在编辑资料页面修改城市时：
1. 更新用户信息 `userInfo.city`
2. 保存到本地存储 `userInfo`
3. 同步到首页的城市选择 `CITY_NAME`
4. 保存到云端时一并更新

```javascript
// pages/profile/edit.js
editCity() {
  wx.showActionSheet({
    itemList: cities,
    success: (res) => {
      const selectedCity = cities[res.tapIndex]
      
      // 1. 更新用户信息
      const userInfo = { ...this.data.userInfo, city: selectedCity }
      this.setData({ userInfo })
      wx.setStorageSync('userInfo', userInfo)
      
      // 2. 同步到首页的城市选择
      wx.setStorageSync('CITY_NAME', selectedCity)
    }
  })
}
```

---

### 3. **页面加载时的同步策略**

#### **首页加载时**（`pages/index/index.js`）
```javascript
onLoad() {
  // 优先从 CITY_NAME 读取
  let cityName = wx.getStorageSync('CITY_NAME')
  
  // 如果没有，从用户信息中读取
  if (!cityName) {
    const userInfo = wx.getStorageSync('userInfo') || {}
    if (userInfo.city) {
      cityName = userInfo.city
      // 同步到 CITY_NAME
      wx.setStorageSync('CITY_NAME', cityName)
    }
  }
  
  if (cityName) {
    this.setData({ cityName })
  }
}
```

#### **编辑资料页加载时**（`pages/profile/edit.js`）
```javascript
async loadUserInfoFromCloud() {
  // 从云端加载用户信息
  const cloudUserInfo = res.result.data
  
  // 如果云端没有城市信息，从首页的城市选择中读取
  if (!cloudUserInfo.city) {
    const savedCity = wx.getStorageSync('CITY_NAME')
    if (savedCity) {
      cloudUserInfo.city = savedCity
    }
  }
  
  this.setData({ userInfo: cloudUserInfo })
}
```

## 📊 数据存储位置

| 存储位置 | 键名 | 用途 |
|---------|------|------|
| 本地存储 | `CITY_NAME` | 首页城市选择 |
| 本地存储 | `userInfo.city` | 用户信息中的城市 |
| 云数据库 | `users.city` | 云端用户信息中的城市 |

## 🎨 用户体验

1. **无感同步**
   - 用户在任何地方修改城市，其他地方自动更新
   - 无需手动同步

2. **数据一致性**
   - 三个存储位置（CITY_NAME、userInfo.city、云端）保持一致
   - 优先级：云端 > 本地存储

3. **智能回退**
   - 如果云端没有城市信息，从本地读取
   - 如果 CITY_NAME 没有，从 userInfo 读取
   - 确保始终有城市显示
