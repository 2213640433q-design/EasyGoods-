# 微信小程序登录功能说明

## 🎯 功能概述

实现了微信小程序的官方登录授权流程，当用户首次使用或未登录时，通过官方授权弹窗获取用户的昵称和头像。

---

## 📋 登录流程（基于图片指示）

### **小程序端实现（4步）**

#### **第一步：获取用户信息**
通过 `wx.getUserProfile()` 方法获取个人信息，包括昵称和头像。

```javascript
const profileRes = await new Promise((resolve, reject) => {
  wx.getUserProfile({
    desc: '获取用户信息用于完善用户资料',
    success: resolve,
    fail: reject
  })
})

const { nickName, avatarUrl } = profileRes.userInfo
```

#### **第二步：获取登录授权码**
通过 `wx.login()` 方法获取登录授权码。

```javascript
const loginRes = await new Promise((resolve, reject) => {
  wx.login({
    success: resolve,
    fail: reject
  })
})

if (loginRes.errMsg !== 'login:ok') {
  throw new Error('登录失败')
}

const code = loginRes.code
```

#### **第三步：封装信息**
将昵称、头像等信息封装。

```javascript
const userInfo = {
  nickname: nickName,
  avatar: avatarUrl
}

// 保存到本地存储
wx.setStorageSync('userInfo', userInfo)
```

#### **第四步：同步到云端**
调用云函数保存用户信息（云函数会自动获取 openid）。

```javascript
const cloudRes = await wx.cloud.callFunction({
  name: 'updateUserInfo',
  data: {
    nickname: nickName,
    avatar: avatarUrl
  }
})
```

---

### **云函数端实现（updateUserInfo）**

云函数会自动处理：
1. 获取用户 openid（通过 `cloud.getWXContext()`）
2. 查询数据库中用户是否存在
3. 存在则更新用户信息
4. 不存在则新建用户数据

```javascript
// cloudfunctions/updateUserInfo/index.js
exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext()
  const openid = wxContext.OPENID
  
  // 查询用户是否存在
  const existResult = await db.collection('users')
    .where({ _openid: openid })
    .get()
  
  if (existResult.data.length > 0) {
    // 用户存在，更新信息
    await db.collection('users')
      .where({ _openid: openid })
      .update({ data: updateData })
  } else {
    // 用户不存在，创建新用户
    updateData._openid = openid
    await db.collection('users').add({ data: updateData })
  }
}
```

## 🔧 关键代码

### **完整的 onLogin 方法**
```javascript
async onLogin() {
  try {
    // 第一步：获取用户信息
    const profileRes = await new Promise((resolve, reject) => {
      wx.getUserProfile({
        desc: '获取用户信息用于完善用户资料',
        success: resolve,
        fail: reject
      })
    })
    
    const { nickName, avatarUrl } = profileRes.userInfo
    
    // 第二步：获取登录授权码
    const loginRes = await new Promise((resolve, reject) => {
      wx.login({
        success: resolve,
        fail: reject
      })
    })
    
    // 第三步：保存到本地
    const userInfo = {
      nickname: nickName,
      avatar: avatarUrl
    }
    this.setData({ userInfo })
    wx.setStorageSync('userInfo', userInfo)
    
    // 第四步：同步到云端
    await wx.cloud.callFunction({
      name: 'updateUserInfo',
      data: {
        nickname: nickName,
        avatar: avatarUrl
      }
    })
    
    wx.showToast({ title: '登录成功', icon: 'success' })
    
  } catch (error) {
    // 错误处理
    if (error.errMsg.includes('getUserProfile:fail auth deny')) {
      wx.showToast({ title: '您拒绝了授权', icon: 'none' })
    }
  }
}
```

## 📝 微信官方 API 说明

### **wx.getUserProfile**
- **用途**：获取用户信息（昵称、头像等）
- **触发**：需要用户主动点击触发
- **授权弹窗**：微信官方弹窗，无法自定义
- **返回数据**：
  ```javascript
  {
    userInfo: {
      nickName: "张三",
      avatarUrl: "https://...",
      gender: 1,
      country: "中国",
      province: "广东",
      city: "广州"
    }
  }
  ```

### **wx.login**
- **用途**：获取登录凭证（code）
- **无需授权**：静默调用
- **返回数据**：
  ```javascript
  {
    code: "0a1b2c3d4e5f6g7h8i9j",
    errMsg: "login:ok"
  }
  ```

1. **官方授权**
   - 使用微信官方授权弹窗

   - 云函数自动获取 openid
   - 前端无需处理敏感信息

3. **数据隔离**
   - 每个用户只能访问自己的数据
   - 基于 openid 自动隔离
