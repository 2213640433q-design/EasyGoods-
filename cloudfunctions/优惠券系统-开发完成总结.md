### **3. 数据库**

#### 📊 **user_coupons 集合（新建）**

**用途：** 存储用户领取的优惠券

**核心字段：**
- `_openid` - 用户标识
- `couponId` - 优惠券模板ID
- `couponName` - 优惠券名称
- `couponType` - 优惠券类型（reduce/discount）
- `discountValue` - 优惠额度
- `minAmount` - 最低消费金额
- `status` - 状态（unused/used/expired）
- `receiveTime` - 领取时间
- `usedOrderId` - 使用的订单ID

**权限配置：**
```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

**用途：** 存储优惠券模板（管理员创建）

**新增字段：**
- `receivedCount` - 领取数量（自动累加）

**权限配置：**
```json
{
  "read": true,
  "write": false
}
```

## 🔄 完整的业务流程

### **流程1：领取优惠券**

```
用户进入领券中心
    ↓
🌟 调用 getAvailableCoupons 云函数
    ↓ (返回可领取优惠券列表)
显示优惠券列表
    ↓
点击"立即领取"
    ↓
🌟 调用 receiveCoupon 云函数
    ↓ (创建 user_coupons 记录，减少库存)
领取成功
    ↓
刷新列表（该优惠券显示"已领取"）
```

### **流程2：在订单中使用优惠券**

```
用户创建订单
    ↓
进入订单确认页
    ↓
🌟 调用 getOrderCoupons 云函数
    ↓ (返回可用优惠券，自动计算优惠金额)
显示"有X张可用"
    ↓
用户点击选择优惠券
    ↓
弹出优惠券列表（按优惠金额排序）
    ↓
选择一张优惠券
    ↓
费用明细中显示优惠券折扣
订单总额自动减少
    ↓
用户提交订单
    ↓
🌟 调用 createOrder 云函数（包含 couponId）
    ↓ (订单中记录优惠券信息)
订单创建成功
    ↓
用户支付订单
    ↓
🌟 调用 updateOrderStatus 云函数（status: paid）
    ↓ (自动标记优惠券为已使用)
支付成功
优惠券状态变为"已使用"
```

## 🎯 核心技术点

### **1. 优惠券领取防重**
```javascript
// 检查是否已领取
const existResult = await db.collection('user_coupons')
  .where({
    _openid: openid,
    couponId: couponId
  })
  .get()

if (existResult.data.length > 0) {
  return { success: false, message: '您已领取过该优惠券' }
}
```

### **2. 优惠券自动过期**
```javascript
// 自动更新过期状态
const now = new Date()
if (coupon.status === 'unused' && new Date(coupon.endTime) < now) {
  await db.collection('user_coupons').doc(coupon._id).update({
    data: { status: 'expired' }
  })
}
```

### **3. 优惠金额自动计算**
```javascript
// 满减券
if (coupon.couponType === 'reduce') {
  discountAmount = coupon.discountValue
}

// 折扣券
if (coupon.couponType === 'discount') {
  discountAmount = orderAmount * (coupon.discountValue / 100)
  if (coupon.maxDiscount && discountAmount > coupon.maxDiscount) {
    discountAmount = coupon.maxDiscount  // 不超过最高优惠
  }
}
```

### **4. 优惠券库存管理**
```javascript
// 领取时减少库存
await db.collection('coupons').doc(couponId).update({
  data: {
    stock: _.inc(-1),        // 库存减1
    receivedCount: _.inc(1)  // 领取数量加1
  }
})
```

### **5. 支付后自动标记已使用**
```javascript
// updateOrderStatus 云函数中
if (newStatus === 'paid' && order.couponId) {
  await db.collection('user_coupons')
    .where({
      _openid: openid,
      couponId: order.couponId,
      status: 'unused'
    })
    .update({
      data: {
        status: 'used',
        usedOrderId: order.orderId,
        usedTime: now
      }
    })
}
```

## 💰 优惠券计算示例

### **示例1：满减券**

```
优惠券：满50减10
订单金额：60英镑（不含押金）
押金：100英镑

计算：
- 小计：60英镑
- 押金：100英镑
- 优惠券：-10英镑
- 订单总额：60 + 100 - 10 = 150英镑
```

### **示例2：折扣券**

```
优惠券：满100享9折，最高优惠20英镑
订单金额：150英镑（不含押金）
押金：100英镑

计算：
- 折扣：150 × 10% = 15英镑
- 小计：150英镑
- 押金：100英镑
- 优惠券：-15英镑
- 订单总额：150 + 100 - 15 = 235英镑
```

### **示例3：折扣券（达到上限）**

```
优惠券：满100享9折，最高优惠20英镑
订单金额：300英镑（不含押金）
押金：150英镑

计算：
- 折扣：300 × 10% = 30英镑，但最高20英镑
- 小计：300英镑
- 押金：150英镑
- 优惠券：-20英镑（上限）
- 订单总额：300 + 150 - 20 = 430英镑
```
