# 🎁 自动发券功能说明

## 📌 功能概述

已为小程序添加**自动发券**功能，包括：

1. **新用户自动发券** - 用户首次进入小程序自动发放2张8折券
2. **批量发券** - 管理员可为所有现有用户发放优惠券

---

## 🎯 功能1：新用户自动发券

### **触发时机：**
用户**首次进入小程序**时自动触发

### **工作流程：**
```
用户打开小程序
    ↓
app.js onLaunch() 执行
    ↓
调用 initNewUser 云函数
    ↓
检查用户是否有优惠券记录
    ├─ 有记录 → 欢迎回来（不发券）
    └─ 无记录 → 新用户！
        ↓
    查找/创建8折券模板
        ↓
    为用户发放2张8折券
        ↓
    显示欢迎弹窗
        ↓
    点击"去查看" → 跳转到优惠券页面
```

### **发放的优惠券：**

**优惠券1：** 小额8折券
- 名称：新人专享8折券（满50可用）
- 类型：折扣券
- 折扣：8折（80%）
- 最低消费：50英镑
- 最高优惠：15英镑
- 有效期：30天

**优惠券2：** 大额8折券
- 名称：新人专享8折券（满100可用）
- 类型：折扣券
- 折扣：8折（80%）
- 最低消费：100英镑
- 最高优惠：30英镑
- 有效期：30天

### **用户体验：**

```
用户首次打开小程序
    ↓
（延迟2秒后）
弹出欢迎提示：
┌─────────────────────────┐
│    欢迎使用！            │
│                         │
│ 已为您发放2张8折优惠券， │
│ 快去查看吧！            │

    ↓
```

## 🎯 功能2：批量发券（管理员功能）

### **使用场景：**
- 节日活动发券
- 促销活动发券
- 补偿发券

### **使用方法：**

在微信开发者工具的控制台执行：

```javascript
// 🎁 给所有用户发放8折券（每人2张）
wx.cloud.callFunction({
  name: 'sendCouponToAllUsers',
  data: {
    couponName: '全场8折优惠券',
    couponType: 'discount',
    discountValue: 20,  // 8折
    minAmount: 50,
    maxDiscount: 20,
    daysValid: 30
  }
}).then(res => {
  console.log('✅ 批量发券结果:', res)
  console.log('  用户数量:', res.result.userCount)
  console.log('  成功发放:', res.result.successCount, '张')
  console.log('  失败数量:', res.result.errorCount)
}).catch(err => {
  console.error('❌ 批量发券失败:', err)
})
```

### **工作流程：**
```
管理员执行云函数
    ↓
查询所有有浏览记录的用户
查询所有有订单记录的用户
    ↓
合并并去重 → 得到所有活跃用户列表
    ↓
创建优惠券模板（保存到 coupons 集合）
    ↓
为每个用户发放2张优惠券
    ├─ 保存到 user_coupons 集合
    └─ 关联优惠券模板ID
    ↓
更新优惠券模板的领取数量
    ↓
返回发放结果
```

### **发放规则：**
- ✅ 只给有浏览记录或订单记录的用户发放
- ✅ 每个用户发放2张
- ✅ 自动创建优惠券模板
- ✅ 自动更新库存和领取数量

## 📊 云函数说明

### **云函数1：initNewUser**

**文件位置：** `cloudfunctions/initNewUser/index.js`

**功能：** 为新用户自动发放欢迎优惠券

**调用方式：** 自动（app.js 中）

**参数：** 无

**返回：**
```javascript
{
  success: true,
  message: '欢迎新用户！已发放优惠券',
  isNewUser: true,      // 是否为新用户
  couponsGiven: 2,      // 发放数量
  coupons: [...]        // 优惠券列表
}
```

**特点：**
- ✅ 自动检测新用户（无优惠券记录）
- ✅ 防止重复发放
- ✅ 自动创建8折券模板（如果不存在）
- ✅ 发放2张不同额度的8折券

---

### **云函数2：sendCouponToAllUsers**

**文件位置：** `cloudfunctions/sendCouponToAllUsers/index.js`

**功能：** 批量为所有活跃用户发放优惠券

**调用方式：** 手动（控制台或管理后台）

**参数：**
```javascript
{
  couponName: '全场8折优惠券',  // 优惠券名称
  couponType: 'discount',      // 类型（discount/reduce）
  discountValue: 20,           // 折扣（20=8折）
  minAmount: 50,               // 最低消费
  maxDiscount: 20,             // 最高优惠
  daysValid: 30                // 有效天数
}
```

**返回：**
```javascript
{
  success: true,
  message: '批量发放完成',
  userCount: 10,        // 活跃用户数
  successCount: 20,     // 成功发放数量
  errorCount: 0,        // 失败数量
  couponId: 'xxx'       // 优惠券模板ID
}
```

**特点：**
- ✅ 自动获取所有活跃用户
- ✅ 每人发放2张
- ✅ 批量处理，高效执行
- ✅ 详细的日志记录

## ⚠️ 注意事项

### **1. 新用户判断标准**

**判断依据：** 用户在 `user_coupons` 集合中**没有任何记录**

**说明：**
- ✅ 首次进入小程序的用户 → 新用户
- ❌ 已领取过任何优惠券的用户 → 老用户
- ❌ 删除所有优惠券后再进入 → 仍视为老用户（不会重复发放）

**如果需要重新测试：**
```
在云开发控制台手动删除你的 user_coupons 记录
然后重新进入小程序
```

---

### **2. 批量发券限制**

**目标用户：** 有浏览记录或订单记录的用户

**说明：**
- ✅ 浏览过商品的用户 → 会收到
- ✅ 下过订单的用户 → 会收到
- ❌ 从未使用过小程序的用户 → 不会收到（因为没有openid记录）

**获取用户来源：**
```javascript
// 从浏览记录获取
const browseUsers = await db.collection('browse_history')
  .field({ _openid: true })
  .get()

// 从订单记录获取
const orderUsers = await db.collection('orders')
  .field({ _openid: true })
  .get()

// 合并去重
const allOpenids = new Set([...browseUsers, ...orderUsers])
```

---

### **3. 发券数量**

**默认：** 每个用户发放 **2张** 相同的优惠券

**如果需要修改：**

编辑 `sendCouponToAllUsers/index.js`，找到：
```javascript
// 为每个用户发放2张相同的优惠券
for (let i = 0; i < 2; i++) {
  // 修改这里的数字：2 → 想要的数量
}
```

---

### **4. 优惠券有效期**

**默认：** 30天

**如果需要修改：**

在调用云函数时传入 `daysValid` 参数：
```javascript
wx.cloud.callFunction({
  name: 'sendCouponToAllUsers',
  data: {
    daysValid: 7  // 修改为7天有效期
  }
})
```
