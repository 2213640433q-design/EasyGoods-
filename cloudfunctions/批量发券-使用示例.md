# 🎁 批量发券 - 使用示例大全

## 📌 功能说明

升级后的 `sendCouponToAllUsers` 云函数，支持**超级灵活**的发券方式！

---

## 🎯 核心特性

### **1. 灵活的目标用户** 👥
- ✅ 所有活跃用户
- ✅ 指定用户（openid列表）
- ✅ 仅新用户

### **2. 灵活的折扣设置** 💰
- ✅ 直接用"X折"表示（8折、9折、7.5折）
- ✅ 满减券（满100减20）
- ✅ 自动计算 discountValue

### **3. 灵活的发放数量** 📊
- ✅ 每人1张/2张/N张
- ✅ 自定义有效期

---

## 📋 参数说明

### **必填参数：**

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `targetType` | String | 目标用户类型 | 'all' / 'specific' / 'new' |
| `couponName` | String | 优惠券名称 | '双11狂欢8折券' |
| `couponType` | String | 优惠券类型 | 'discount' / 'reduce' |

### **折扣券参数（couponType='discount'）：**

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `discount` | Number | 折扣 | 8（表示8折） |
| `minAmount` | Number | 最低消费（英镑） | 50 |
| `maxDiscount` | Number | 最高优惠（英镑，可选） | 20 |

### **满减券参数（couponType='reduce'）：**

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `reduceAmount` | Number | 减免金额（英镑） | 20 |
| `minAmount` | Number | 最低消费（英镑） | 100 |

### **可选参数：**

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `quantity` | Number | 每人发放数量 | 1 |
| `daysValid` | Number | 有效天数 | 30 |
| `userList` | Array | 指定用户列表 | [] |

## 🌟 使用示例

### **场景1：给所有用户发8折券（每人2张）** ⭐

```javascript
wx.cloud.callFunction({
  name: 'sendCouponToAllUsers',
  data: {
    targetType: 'all',  // 所有活跃用户
    couponName: '全场8折优惠券',
    couponType: 'discount',
    discount: 8,  // 8折（80%）
    minAmount: 50,
    maxDiscount: 20,
    quantity: 2,  // 每人2张
    daysValid: 30
  }
}).then(res => {
  console.log('✅ 发券结果:', res.result)
})
```

**效果：**
- 所有有浏览/订单记录的用户
- 每人获得2张8折券
- 满50可用，最高优惠20英镑
- 30天有效期

## 📊 折扣计算说明

### **折扣券（discount）**

**参数对应关系：**

| discount参数 | 实际折扣 | 折扣率 | discountValue |
|-------------|---------|-------|---------------|
| 8 | 8折 | 80% | 20 |
| 9 | 9折 | 90% | 10 |
| 7.5 | 7.5折 | 75% | 25 |
| 6.5 | 6.5折 | 65% | 35 |

**计算公式：**
```javascript
discountValue = 100 - (discount × 10)

示例：
discount = 8 → discountValue = 100 - 80 = 20
discount = 9 → discountValue = 100 - 90 = 10
discount = 7.5 → discountValue = 100 - 75 = 25
```

**优惠计算：**
```
订单金额 × (100% - 折扣率) = 优惠金额

示例（8折券，订单100英镑）：
100 × (100% - 80%) = 100 × 20% = 20英镑
如果有最高优惠限制（maxDiscount=15），则优惠15英镑
```

---

### **满减券（reduce）**

**参数对应关系：**

| reduceAmount | 优惠效果 | discountValue |
|-------------|---------|---------------|
| 10 | 减10英镑 | 10 |
| 20 | 减20英镑 | 20 |
| 50 | 减50英镑 | 50 |

**优惠计算：**
```
订单金额 >= minAmount → 直接减 reduceAmount

示例（满100减20）：
订单120英镑 → 优惠20英镑 → 支付100英镑
订单80英镑 → 不可用
```

## 🔍 如何获取用户openid？

### **方法1：从云开发控制台查看**

```
1. 云开发 → 数据库
2. 选择 browse_history 或 orders 集合
3. 查看记录，复制 _openid 字段
```

### **方法2：从日志查看**

```
1. 云开发 → 云函数 → initNewUser
2. 查看日志
3. 找到用户的 openid
```

### **方法3：通过云函数查询**

```javascript
// 在控制台执行
wx.cloud.database()
  .collection('browse_history')
  .field({ _openid: true })
  .limit(10)
  .get()
  .then(res => {
    const openids = res.data.map(r => r._openid)
    const unique = [...new Set(openids)]
    console.log('用户openid列表:', unique)
  })
```

## ⚠️ 注意事项

### **1. discount 和 reduceAmount 的区别**

**折扣券（discount）：**
```javascript
discount: 8        // 表示8折（80%）
discount: 9        // 表示9折（90%）
discount: 7.5      // 表示7.5折（75%）
```

**满减券（reduce）：**
```javascript
reduceAmount: 20   // 表示减20英镑
reduceAmount: 50   // 表示减50英镑
```

---

### **2. targetType 的选择**

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| `all` | 所有有浏览/订单记录的用户 | 全民活动、节日促销 |
| `specific` | 指定openid列表 | VIP专属、定向补偿 |
| `new` | 无优惠券记录的新用户 | 拉新活动、新人福利 |

---

### **3. quantity 的使用**

```javascript
quantity: 1   // 每人1张
quantity: 2   // 每人2张（推荐，给用户选择空间）
quantity: 5   // 每人5张（VIP专属）
```
