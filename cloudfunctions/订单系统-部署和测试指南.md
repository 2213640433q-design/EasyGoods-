## 📋 部署步骤

### **第1步：创建 orders 集合** 📊

1. 打开微信开发者工具
2. 点击 "云开发" 按钮
3. 选择 "数据库" 标签
4. 点击 "+" 创建集合
5. 输入集合名称：`orders`
6. 点击 "确定"

#### **配置权限：**

1. 点击 `orders` 集合
2. 点击 "权限设置"
3. 选择 "自定义安全规则"
4. 输入以下规则：

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

5. 点击 "保存"

✅ 完成后，用户只能查看和修改自己的订单。

## ⚠️ 常见问题

### **问题1：云函数调用失败**

**错误信息：** `cloud.callFunction:fail`

**解决方案：**
```
1. 检查云函数是否已部署成功
2. 检查云环境是否正确初始化（app.js 中的 env 配置）
3. 尝试重新上传云函数
4. 检查网络连接
```

### **问题2：数据库查询返回0条记录**

**原因：** 权限配置问题或 `_openid` 字段缺失

**解决方案：**
```
1. 检查 orders 集合的权限规则是否正确
2. 检查云函数中是否正确添加了 _openid 字段
3. 在云开发控制台直接查看数据库记录，确认 _openid 字段存在
```

### **问题3：订单创建成功，但列表中看不到**

**原因：** 数据格式不匹配或权限问题

**解决方案：**
```
1. 清除缓存并重新编译
2. 检查 getOrders 云函数的查询条件
3. 检查前端的数据格式化逻辑
4. 在控制台执行 getOrders 测试命令，查看返回数据
```

### **问题4：支付后状态未更新**

**原因：** `updateOrderStatus` 云函数调用失败

**解决方案：**
```
1. 检查控制台错误日志
2. 检查 orderId 是否正确传递
3. 检查 updateOrderStatus 云函数是否部署成功
4. 手动在控制台测试 updateOrderStatus 云函数
```
