# 📊 云数据库初始化指南

## 🎯 第一步：创建数据库集合

### 在微信开发者工具中操作

1. **打开云开发控制台**
   ```
   点击工具栏的"云开发"按钮 → 进入云开发控制台
   ```

2. **创建以下集合（Collection）**

#### 1️⃣ products（商品表）
```
集合名称: products
权限设置: 所有用户可读，仅管理员可写
```

**字段说明：**
```javascript
{
  _id: String,              // 自动生成
  name: String,             // 商品名称
  subtitle: String,         // 副标题
  mainCategory: String,     // 主分类（娱乐/摄影/户外/其他）
  subCategory: String,      // 子分类（麻将/CCD/帐篷等）
  price: Number,            // 日租金
  deposit: Number,          // 押金
  images: Array<String>,    // 图片URL数组
  description: String,      // 商品描述
  accessories: String,      // 配件说明
  specs: Array<Object>,     // 规格参数
  stock: Number,            // 库存数量
  rentedCount: Number,      // 已租次数
  status: String,           // 状态：valid/offline/sold
  stores: Array<String>,    // 可租门店
  createdAt: Date,          // 创建时间
  updatedAt: Date           // 更新时间
}
```

#### 2️⃣ orders（订单表）
```
集合名称: orders
权限设置: 仅创建者可读写
```

**字段说明：**
```javascript
{
  _id: String,
  _openid: String,          // 用户openid（自动添加）
  orderId: String,          // 订单号
  productId: String,        // 商品ID
  productName: String,      // 商品名称
  productImage: String,     // 商品图片
  status: String,           // 订单状态：pending/paid/picked/checking/completed
  rentalStartDate: String,  // 租赁开始日期
  rentalEndDate: String,    // 租赁结束日期
  rentalDays: Number,       // 租赁天数
  storeName: String,        // 门店名称
  storeAddress: String,     // 门店地址
  storePhone: String,       // 门店电话
  equipmentPrice: Number,   // 设备费用
  accessoriesPrice: Number, // 配件费用
  totalPrice: Number,       // 租金总计
  deposit: Number,          // 押金
  totalAmount: Number,      // 总金额
  payTime: Date,            // 支付时间
  pickTime: Date,           // 取货时间
  returnTime: Date,         // 归还时间
  completeTime: Date,       // 完成时间
  createdAt: Date,          // 创建时间
  updatedAt: Date           // 更新时间
}
```

#### 3️⃣ users（用户表）
```
集合名称: users
权限设置: 仅创建者可读写
```

**字段说明：**
```javascript
{
  _id: String,
  _openid: String,          // 用户openid（自动添加）
  nickname: String,         // 昵称
  avatar: String,           // 头像URL
  phone: String,            // 手机号
  school: String,           // 学校
  isVerified: Boolean,      // 是否实名认证
  createdAt: Date,          // 注册时间
  lastLoginAt: Date         // 最后登录时间
}
```

#### 4️⃣ addresses（收货地址表）
```
集合名称: addresses
权限设置: 仅创建者可读写
```

**字段说明：**
```javascript
{
  _id: String,
  _openid: String,          // 用户openid（自动添加）
  name: String,             // 收货人
  phone: String,            // 手机号
  address: String,          // 详细地址
  postcode: String,         // 邮编
  isDefault: Boolean,       // 是否默认地址
  createdAt: Date           // 创建时间
}
```

#### 5️⃣ coupons（优惠券表）
```
集合名称: coupons
权限设置: 所有用户可读，仅管理员可写
```

**字段说明：**
```javascript
{
  _id: String,
  name: String,             // 优惠券名称
  amount: Number,           // 优惠金额
  threshold: Number,        // 使用门槛
  expiryDate: String,       // 过期日期
  rules: String,            // 使用规则
  total: Number,            // 发行总量
  remaining: Number,        // 剩余数量
  status: String,           // 状态：active/inactive
  createdAt: Date           // 创建时间
}
```

#### 6️⃣ user_coupons（用户优惠券关联表）
```
集合名称: user_coupons
权限设置: 仅创建者可读写
```

**字段说明：**
```javascript
{
  _id: String,
  _openid: String,          // 用户openid（自动添加）
  couponId: String,         // 优惠券ID
  couponName: String,       // 优惠券名称
  amount: Number,           // 优惠金额
  threshold: Number,        // 使用门槛
  expiryDate: String,       // 过期日期
  status: String,           // 状态：unused/used/expired
  usedAt: Date,             // 使用时间
  receivedAt: Date          // 领取时间
}
```

## 🔒 第三步：配置数据库权限

### 推荐权限设置

1. **products（商品表）**
   - 所有用户可读
   - 仅管理员可写

2. **orders（订单表）**
   - 仅创建者可读写
   - 用户只能看到自己的订单

3. **users（用户表）**
   - 仅创建者可读写
   - 用户只能读写自己的信息

4. **addresses（地址表）**
   - 仅创建者可读写
   - 用户只能管理自己的地址

5. **coupons（优惠券表）**
   - 所有用户可读
   - 仅管理员可写

6. **user_coupons（用户优惠券表）**
   - 仅创建者可读写
   - 用户只能看到自己的优惠券

### 权限设置示例

```json
{
  "read": true,
  "write": "doc._openid == auth.openid"
}
```
