# EasyGoods-租赁小程序

这是从原EasyGoods项目拆分出来的**租赁**专用小程序。

## 功能特点

### 📱 页面结构
- **首页**：仅展示租赁商品列表（相机、镜头、无人机等设备）
- **我的**：个人中心，仅保留租赁相关功能

### 🎯 核心功能
1. **租赁商品浏览**
   - 分类筛选（全部、摄像机、相机、无人机、配件）
   - 搜索功能
   - 商品详情查看

2. **我的租赁**
   - 查看租赁订单
   - 订单详情
   - 订单状态跟踪

3. **通用功能**
   - 城市选择（左上角）
   - 消息通知
   - 个人资料编辑
   - 收藏功能

### 🗂 目录结构
```
EasyGoods-租赁/
├── pages/
│   ├── index/           # 首页（仅租赁）
│   ├── profile/         # 个人中心
│   ├── rental/          # 租赁相关页面
│   ├── orders/          # 订单页面
│   ├── message/         # 消息页面
│   ├── chat/            # 聊天页面
│   ├── favorites/       # 收藏页面
│   └── about/           # 关于页面
├── components/          # 公共组件
├── static/              # 静态资源
└── utils/               # 工具函数
```

- 首页

- 我的

## 开发说明

### 启动项目
1. 使用微信开发者工具打开此目录
2. 填入appid（在 `project.config.json` 中）
3. 开始调试

### 图片资源优化
- 原1.02MB的PNG logo已替换为轻量级SVG版本
- SVG文件路径：`/static/icons/easygoods-logo.svg`

## 与原项目的区别
- ❌ 移除了集市相关功能
- ❌ 移除了发布商品功能
- ✅ 保留了租赁核心业务
- ✅ 保留了用户基本功能
- ✅ 保留了消息聊天功能

## 技术栈
- 微信小程序原生开发
- Skyline渲染引擎
- Glass-easel组件框架
