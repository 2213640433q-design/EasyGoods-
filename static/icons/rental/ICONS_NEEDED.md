# 租赁功能图标需求

## 需要添加的图标文件

请在 `/static/icons/rental/` 目录下添加以下4个图标文件：

### 1. address.png - 收货地址
- **建议图标**：📍 地址定位图标、房子图标、地图图标
- **颜色**：彩色或深色（PNG透明背景）
- **建议配色**：紫色系 (#667eea) 或深灰色 (#1D1D1F)
- **尺寸**：建议 128x128px 或更高
- **风格**：线性图标或面性图标均可

### 2. verify.png - 实名认证
- **建议图标**：✓ 对勾图标、身份证图标、认证徽章图标
- **颜色**：彩色或深色（PNG透明背景）
- **建议配色**：粉红色系 (#f093fb) 或深灰色 (#1D1D1F)
- **尺寸**：建议 128x128px 或更高
- **风格**：线性图标或面性图标均可

### 3. deposit.png - 我的押金
- **建议图标**：💰 钱袋图标、钱币图标、钱包图标
- **颜色**：彩色或深色（PNG透明背景）
- **建议配色**：蓝色系 (#4facfe) 或深灰色 (#1D1D1F)
- **尺寸**：建议 128x128px 或更高
- **风格**：线性图标或面性图标均可

### 4. service.png - 在线客服
- **建议图标**：💬 客服对话图标、耳机图标、服务图标
- **颜色**：彩色或深色（PNG透明背景）
- **建议配色**：绿色系 (#43e97b) 或深灰色 (#1D1D1F)
- **尺寸**：建议 128x128px 或更高
- **风格**：线性图标或面性图标均可

## 设计要求

1. **背景**：PNG格式，透明背景
2. **图标颜色**：
   - 可使用彩色（建议使用对应的主题色）
   - 或使用深灰色 (#1D1D1F) 统一风格
3. **尺寸**：
   - **推荐尺寸**：84x84px（2倍图）或 112x112px（3倍图）
   - **显示尺寸**：28x28px（小而精致）
   - **最小尺寸**：56x56px
4. **风格**：保持一致，建议使用线性风格或扁平化风格
5. **粗细**：建议线条粗细为 2-3px（如果是线性图标）
6. **留白**：图标四周建议留 10-15% 的留白空间，确保视觉平衡

## 颜色建议

图标可以使用以下主题色（也可使用统一的深灰色）：
- **收货地址**：紫色系 (#667eea)
- **实名认证**：粉红色系 (#f093fb)
- **我的押金**：蓝色系 (#4facfe)
- **在线客服**：绿色系 (#43e97b)

## 临时方案

在正式图标准备好之前，可以：
1. 使用纯色占位图
2. 使用文字代替
3. 暂时使用emoji表情

## 文件路径

```
/static/icons/rental/
  ├── address.png    (收货地址)
  ├── verify.png     (实名认证)
  ├── deposit.png    (我的押金)
  └── service.png    (在线客服)
```

添加完成后，小程序会自动加载这些图标。
