# 主导航图标

此文件夹包含首页主导航的图标。

## 图标列表

- `all.png` - 全部图标
- `entertainment.png` - 娱乐图标
- `photography.png` - 摄影图标
- `outdoor.png` - 户外图标
- `other.png` - 其他图标

## 设计规范

- **尺寸**: 建议 84x84px（3倍图）或 56x56px（2倍图）
- **显示尺寸**: 28x28px
- **格式**: PNG（透明背景）
- **风格**: 简约、线性或面性图标
- **颜色**: 彩色或深灰色 (#1D1D1F)

## 建议图标

- **全部**: 🏠 首页、📋 全部、⊞ 网格图标
- **娱乐**: 🎮 游戏手柄、🎵 音符、🎪 娱乐图标
- **摄影**: 📷 相机、🎬 摄影机图标
- **户外**: ⛺ 帐篷、🏕️ 露营图标
- **其他**: ⋯ 更多、📋 列表图标

## 使用场景

这些图标用于首页顶部主导航栏：
```
[娱乐] [摄影] [户外] [日常] [其他]
```

添加图标后，导航栏会自动加载显示。
