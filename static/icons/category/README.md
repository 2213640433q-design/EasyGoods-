# 分类图标

此文件夹包含首页分类相关的图标。

## 图标列表

### 娱乐类
- `mahjong.png` - 麻将图标
- `poker.png` - 德州扑克图标
- `dice.png` - 骰子图标
- `speaker.png` - 蓝牙音箱图标
- `projector.png` - 投影仪图标

### 摄影类
- `action-camera.png` - 运动相机图标
- `ccd.png` - CCD相机图标
- `camera.png` - 摄像机图标
- `drone.png` - 无人机图标

### 户外类
- `picnic.png` - 野餐垫图标
- `tent.png` - 帐篷图标
- `chair.png` - 折叠椅图标
- `grill.png` - 烧烤架图标
- `light.png` - 露营灯图标

## 设计规范

- **尺寸**: 建议 84x84px（2倍图）或 112x112px（3倍图）
- **显示尺寸**: 28x28px
- **格式**: PNG（透明背景）
- **风格**: 简约、线性或面性图标
- **颜色**: 彩色或深灰色 (#1D1D1F)

## 使用场景

这些图标用于首页分类展示：
```
娱乐 | [麻将] [德州扑克] [骰子] [更多]
       ↑icon  ↑icon     ↑icon  ↑···
```

## 临时方案

在正式图标准备好之前，可以：
1. 使用占位图片
2. 使用emoji表情
3. 使用纯色占位

添加图标后，分类栏会自动加载显示。
